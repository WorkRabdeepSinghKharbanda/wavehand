`/blog` lists all `src/content/blogPosts.ts` entries with a client-side search box (filters on title/description, no backend); `/blog/:slug` renders one. Each post is structured as `sections` (real H2 headings, each with paragraphs — not a flat paragraph list), a `faq` array (rendered visibly and emitted as FAQPage JSON-LD), and an optional `image` (a real screenshot from `public/screenshots/`, used as the hero and as og:image — never a scraped internet image). Posts are long-form (roughly 1200–2000 words); `/blog/:slug` also renders breadcrumbs, a related-posts block, and an `AdSlot`. Adding a post is appending one array entry — no new component or route needed, per `brain-sync.md`. `sitemap.xml` is generated automatically at build time (`scripts/generate-sitemap.mjs`); only `public/llms.txt` needs a manual update in the same change (noted as a comment at the top of `blogPosts.ts` too). Posts emit `BlogPosting` JSON-LD. Every post describes real app mechanics (MediaPipe finger/wrist-tilt reading, the chord stabilizer, Learn mode's correctness gating, the v1/v2 arrangement format split, the voice picker's loudness compensation, real engineering postmortems like the StrictMode camera bug and the Core Web Vitals fixes) — content is written to stay accurate to the actual code, not marketing copy. Unknown `:slug` renders `NotFoundPage`.
